Camilla na Cozinha

Rápido • Prático • Gostoso

Site de receitas desenvolvido como trabalho de Desenvolvimento Web do curso técnico de Desenvolvimento de Sistemas do Instituto Federal (IF Sudeste MG). O projeto reúne as atividades das Unidades 2, 3 e 4: HTML, CSS e JavaScript.

Veja o site: https://github.com/CamillaViana/projeto-site-Camilla-na-Cozinha.git

O que tem no site
18 receitas em cartões, organizadas por grupos: Salgados, Sopas, Pastas, Bolos, Doces e Bebidas
Busca por receita ou ingrediente
Filtro por categoria
Botão para sortear uma receita
Botão de favoritar, com contador de receitas favoritas (fica salvo no navegador)
Tabela com o resumo das receitas
Formulário "Sugira uma receita", com validação dos campos
Tecnologias
Tecnologia	Para que foi usada
HTML	Estrutura da página: cabeçalho, menu, cartões, tabela e formulário
CSS	Cores, fontes, espaçamentos, bordas e organização visual
JavaScript	Busca, filtro, favoritos, sorteio e validação do formulário
Como cada unidade aparece no projeto
Unidade 2 (HTML): títulos, parágrafos, listas, links, imagens, tabela, formulário e tags semânticas (header, nav, main, section, article, footer).
Unidade 3 (CSS): paleta em turquesa e coral, fonte Comic Sans, margin e padding, bordas arredondadas e cartões lado a lado com flex.
Unidade 4 (JavaScript): variáveis, funções, condicionais, repetição, eventos de clique e alteração do conteúdo da página.
